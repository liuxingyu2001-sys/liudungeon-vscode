# 三、五分钟上手

> [← 二、安装与依赖](02-安装与依赖.md) · [总目录](../05-使用说明.md) · [四、指令手册 →](04-指令手册.md)

假设你已经有一张想做成副本的地图。

## 步骤 0：先有一个副本

插件首次启动会写出演示副本 `dungeons/example/`，可以直接照抄；要建自己的副本，一条指令就够：

> 演示副本**不会出现在 GUI 菜单与 `/ld list` 里**（连管理员也不显示）——
> 它是插件自己的演示数据，不是你建的副本。想看它长什么样：`/ld enter example`。
> 复制它请用 `/ld create` 建一份自己的，别直接改它。

```
/ld create crypt                 # 不写模板名 → 用途中能用的那张（默认内置虚空世界）
/ld create crypt forgedungeon    # 顺手把 world.template 写成 forgedungeon
```

它会建好 `plugins/liudungeon/dungeons/crypt/`，写入 10 个配置文件（`config.yml` 里逐段都有注释），
把 `config.yml` 的展示名与 `world.template` 改成这个副本该有的值，然后自动重载 ——
`/ld list` 立刻能看到它。

**不写模板名时的默认值**（按"建完就能进"排优先级）：

1. 有与副本同名的模板 → 用它（地图与副本叫一个名字的老习惯）；
2. 否则用**内置虚空世界 `voidgen`** —— 插件首次启动就自己生成好了，所以**刚装好的服务器不导入任何地图，
   也能 `/ld create` 出一个进得去的副本**。

想用自己的地图，再按下面的步骤 1 导入（步骤 1 是可选的）。

下面就以副本 `crypt` 为例；如果你直接沿用示例副本，把命令里的 `crypt` 换成 `example` 即可。

每个副本目录里都有一份 `说明.md`（30 秒速览）：流程长什么样、每个文件干什么、想改什么去哪个文件、出问题先看哪里。**内置示例刻意做得很薄** —— 两波怪、5 行有效脚本就构成一条完整主线（清小怪 → 打 Boss → 通关发奖），其余文件只有注释，想要那类玩法时再打开。

## 步骤 1：把地图导入为模板（可选 —— 用内置虚空世界就跳过）

> **不导入也能玩。** 插件内置了一张虚空世界 `voidgen`（一层基岩地板 + 什么都没有，
> 磁盘上只有几百字节，区块由服务端现生成），新建的副本默认就用它。
> 想自己从头搭地牢，直接跳到步骤 3。想用自己的地图，继续往下。


地图可以放在任何地方，插件按以下顺序查找同名地图：

1. 服务器根目录 `./<地图名>/`
2. 各世界的维度目录 `./<世界>/dimensions/minecraft/<地图名>/`
3. 已经导入过的 `plugins/liudungeon/maps/<模板名>/`

执行：

```
/ld template import forgedungeon
```

> 地图有多个候选来源、或想改个模板名时：
> `/ld template import <地图名> <模板名> [--overwrite]`
> 加 `--overwrite` 覆盖已存在的模板。Tab 补全第三段会自动列出所有可导入的地图。

导入后模板位于 `plugins/liudungeon/maps/forgedungeon/`。

## 步骤 2：指向模板并设置出生点

编辑 `plugins/liudungeon/dungeons/<你的副本ID>/config.yml`（用 `/ld create` 建的副本已经把模板名写好了，这一步通常只需核对出生点）：

```yaml
world:
  # 模板名，对应 plugins/liudungeon/maps/<这个名字>/
  #   不导入地图时保持 voidgen（内置虚空世界，地板在 y=64，所以出生点写 65）
  template: forgedungeon
  # 出生点 x,y,z,yaw,pitch —— 不需要精确，插件会自动找安全落脚点
  spawn: '0,70,0,0,0'
```

## 步骤 3：体检

```
/ld reload
/ld doctor
```

`/ld doctor` 会检查副本配置、脚本条件表达式、地图模板是否就绪。把报的每条问题都清掉再往下走。

## 步骤 4：进本

```
/ld enter crypt          # 用 /ld create 建的副本 ID；示例副本则是 /ld enter example
```

进本时观察控制台，正常应该是这样：

```
[进本] bluec 请求进入「example」，参与成员 1 人: bluec
[进本] 校验通过（人数/等级/权限/冷却/金币/门票 全部满足）
[进本] 开始异步克隆模板「forgedungeon」→「ld_forgedungeon_82f8f213」
[进本] 模板克隆完成，用时 17 ms
[进本] 世界加载完成: ld_forgedungeon_82f8f213（已加载区块 25），配置出生点 0,70,0 → 安全落脚点 -2,67,-1
[进本] 已传送 bluec → ld_forgedungeon_82f8f213 @ -2,67,-1
[进本] 执行 init 脚本（3 行）
[进本] 执行 start 脚本（2 行）
[进本] 「example」开本完成，用时 0 秒，参与 1 人
```

**`已加载区块` 必须是正数。** 如果是 0，说明模板的区块布局有问题，见 [10.2](10-排错与常见问题.md#102-进本后一片空白--掉虚空)。

## 步骤 5：给玩家开菜单

```
/ld menu
```

没有参数时打开主菜单：地牢列表、我的队伍、我的数据。

## 步骤 6：想改副本内容

配置跑通之后，出生点、区域范围、点位、交互点、怪物刷新点这些**坐标类内容**
不用手写坐标 —— 进游戏里点方块就行：

```
/ld edit enter example
```

拿到 8 件工具，选目标 → 点世界 → `/ld edit save` → `/ld edit test` 立刻进本试玩。
想快点圈一片范围：拿包里的 &f⬛区域快速创建器&r `Shift+右键` 开工，再右键点两个点就是一个区域（自带「中心」点位）。
完整走查、工具/命令/GUI 速查、以及「点一下到底改了哪个 YAML 键」，见
**[十二、游戏内编辑模式](12-游戏内编辑模式.md)**。
